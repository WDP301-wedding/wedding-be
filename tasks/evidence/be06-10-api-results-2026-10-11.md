# Báo cáo kiểm tra API bước 4 — 2026-10-11

Phạm vi: BE-06–10, wedding-be, nhánh codex/commercial-contracts-step-4.

## Kết quả cuối

- Bộ API mới: 5 kịch bản đạt, 102 yêu cầu HTTP, bao quát 11 endpoint.
- Toàn bộ backend: **192 file / 1.530 test đạt**, không có test lỗi; lần chạy cuối mất 302,71 giây. Log: [step4-full-suite-final.log](../../test-results/step4-full-suite-final.log).
- Typecheck, lint, OpenAPI artifact check và kiểm tra định dạng các file test thay đổi: đạt.
- Database thử đã áp dụng đủ 31 migration. PDF hai trang được render và kiểm tra trực quan.
- Lần hồi quy đầu có 31 test lỗi: database nền thử chưa có migration, mock legacy thiếu các trường nullable mới và fixture nâng cấp dùng client hiện tại trên schema lịch sử. Đã sửa chuẩn bị database/mock/fixture schema cũ, giữ nguyên kiểm tra lịch sử và constraint; không sửa logic production trong lượt kiểm tra này.
- Chưa chạy coverage, kiểm chứng toàn bộ race/concurrency hoặc thanh toán VNPay sandbox thật. Báo cáo này xác nhận các kịch bản đã chạy, chưa đóng toàn bộ nghiệm thu BE-06–10.

Môi trường: Express/Supertest qua HTTP loopback, Identity session/quyền và PostgreSQL 17 thật. Database riêng được tạo mới, chạy toàn bộ migration theo thứ tự rồi xóa sau test. Không dùng database Supabase chung.

VNPay: cấu hình/khoá/chữ ký kiểm soát của bộ test, gateway ngoại mạng bị thay bằng lỗi có kiểm soát. Không mở checkout, gọi QueryDr hay thanh toán sandbox thật. UNKNOWN khi tra cứu trước callback là kết quả đúng của gateway không phản hồi; giữ chỗ không bị giải phóng.

Bộ mới gồm 5 kịch bản tự động, 102 yêu cầu HTTP gồm dữ liệu chuẩn bị, sáu API hợp đồng và năm API thanh toán/callback/lịch sử liên quan. Chi tiết đầy đủ: [responses.json](../../test-results/step4-api/responses.json). Mỗi mã 4xx dưới đây là kết quả từ chối mong đợi đã được kiểm tra.

Hợp đồng mẫu: 10 bàn x 3.500.000 + 2 bàn x 4.500.000 + MC 2.500.000 + 100 thiệp x 5.000 = **47.000.000 VND**. Cọc 30% = **14.100.000 VND**. Còn phải trả **32.900.000 VND**. Callback/gửi lại không tạo thêm CHARGE/PAYMENT.

PDF: file thực tải từ API, 2 trang; kiểm tra nội dung/dấu tiếng Việt, điều khoản bắt buộc, giá trị, phân trang và SHA-256 khớp. PDF cũ giữ nguyên byte sau rút duyệt. [File thử](../../test-results/step4-api/approved-contract.pdf).

Cấu hình thử đặt giới hạn 1.000 yêu cầu/phút cho ma trận API; giới hạn mặc định ứng dụng 100/phút giữ nguyên. Lần chạy đầu có kỳ vọng nhầm với Booking legacy, đã sửa fixture để chuyển sang hợp đồng mới trước khi kiểm tra bắt buộc duyệt. Lần sau chạm 429 do khối lượng test, đã điều chỉnh cấu hình thử.
